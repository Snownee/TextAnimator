# Text Animator for Minecraft 1.21.1 (Fabric)

This port targets **Minecraft 1.21.1** on Fabric Loader **0.17.2** with Fabric API **0.116.6+1.21.1**. It requires **Java 21** and Gradle **8.14.2**.

## Building

```bash
./gradlew build
```

The built jar will be located in `build/libs/`.
